# Inst377-Final-Project-app
Final project: 

Anime-World

web link:inst377-final-project-app.vercel.app

Description:

This webpage is designed to bring anime fans something unique. This application helps you find new or old anime to watch, allows you to post your theory and other comments, shows the user top animes based on their score rating and finally a small random anime quote. 

Little in depth the find anime works by users picking their favorite genre and episode length then the page will show a max 3 results to recommend based on what you choose. 

Target browsers: 

The Anime-World application's main targeted browsers are:
-Chrome
-Safari 
-Firefox
-Microsoft Edge
-Brave and Duckduckgo.
